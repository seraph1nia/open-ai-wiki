# AI Knowledge Quickstart

This knowledge base maintains a durable corpus about **AI protocols, frameworks, concepts, standards, and technically useful references**, grounded only in configured external connectors and their retrieved evidence.

## Current status

As of this update (2026-09-19), the wiki documents the **Model Context Protocol core** (added 2026-08-17; refreshed 2026-08-18, 2026-08-22, 2026-08-27, 2026-08-29 and 2026-09-19), two **agent protocols**, a **generative-UI / agent-UI** domain, and the **agentic SDLC factory toolchain** (incl. its CI-native gh-aw and gateway layers), plus the **agent-maintained knowledge-base** layer (OKF v0.2 in its canonical open-knowledge-format repo, OpenWiki):

**Model Context Protocol (added 2026-08-17; refreshed 2026-08-18, 2026-08-22, 2026-08-27, 2026-08-29 and 2026-09-19):**
- **[Model Context Protocol (MCP)](/protocols/model-context-protocol.md)** — the industry-standard, open JSON-RPC 2.0 protocol for connecting AI agents to external tools, data, and other agents. Its **2026-07-28 revision** made the protocol core **stateless** (no handshake or session), added **Multi Round-Trip Requests (MRTR)**, header-based routing, cacheable list results, full JSON Schema 2020-12 for tool schemas, authorization hardening (RFC 9207 `iss` validation, DCR deprecated for CIMD), **Tasks** as an extension, a formal **extensions framework**, and a 12-month feature-lifecycle/deprecation policy — with the maintainer team expanded 2026-04-08 (**Clare Liguori** → Core Maintainer, **Den Delimarsky** → second Lead Maintainer). The **MCP Registry** is an open-source Go service (permissive license, sub-registry API). The **2026-08-22 "New MCP Roadmap"** supersedes the March roadmap with five priority areas (see the [roadmap section](/protocols/model-context-protocol.md#2026-roadmap-and-governance)). Its [Releases reference](/references/model-context-protocol-releases.md) maps the versioned spec revisions (2025-03-26 → 2026-07-28, now with the **source-backed `2026-07-28` stable release tag** on the spec repo), the Tier 1 SDK posture (all four speak the revision; TypeScript v2.0.0 monorepo split; **Java SDK v2.0.0 GA** tracking 2025-11-25; **C# SDK list at v2.2.0** — watchlist), and the official `servers` + `swift-sdk` + `mcpb` + `registry` release trails.

**Agent protocols (pre-existing):**
- The **[Agent Host Protocol (AHP)](/protocols/agent-host-protocol.md)** — Microsoft's synchronized, multi-client state protocol for AI agent sessions, framed on JSON-RPC 2.0 with channel-based routing, immutable state, pure reducers, and write-ahead reconciliation. Its [Releases reference](/references/agent-host-protocol-releases.md) maps the spec request through v0.7.0 (2026-07-31); evidence lives on the [GitHub source page](/sources/github-agent-host-protocol.md).
- The **[Agent Client Protocol (ACP)](/protocols/agent-client-protocol.md)** — the editor↔agent protocol for "connecting any editor to any agent" (specified in the `agentclientprotocol` org). Added in an earlier run via its official TypeScript implementation, with a [Releases reference](/references/agent-client-protocol-typescript-sdk-releases.md) through v1.3.0 (2026-07-21) and [source evidence](/sources/github-acp-typescript-sdk.md).

**Generative-UI / agent-UI (added 2026-08-16 from the web-search generative-UI run):**
- **[AG-UI](/protocols/ag-ui.md)** — the event-based agent-user-interaction wire protocol (~16 event types over SSE/WS/HTTP); SDK surface now spans official TypeScript/Python plus Java, Go, Kotlin (community), Swift (community), and — as of the 2026-09-19 re-pull — **.NET ✅ Supported (Community)** in the README SDKs table.
- **[A2UI](/protocols/a2ui.md)** — the declarative, no-code-execution "Agent to UI" JSON protocol (Surfaces, Components, Catalogs). The 2026-09-19 re-pull added the **Lynx renderer (ReactLynx) as ✅ Stable for v0.9**, the three-path how-to routing (Host app / Agent / Existing framework — the last naming AG-UI/CopilotKit and Flutter GenUI), and the v0.8↔v0.9 evolution guide detail.
- **[MCP Apps](/protocols/mcp-apps.md)** — the first official [Model Context Protocol](/protocols/model-context-protocol.md) extension (Anthropic + OpenAI), delivering interactive UIs in CSP-sandboxed iframes; the 2026-08-22 re-pull deepened the interface surface (ui:// tool-linked resources, JSON-RPC-over-`postMessage` communication, tool visibility, host context/theming, display modes, 5-phase lifecycle incl. Teardown), the 2026-08-29 re-pull added the View-side `App` runtime API (`app.connect()`, `app.ontoolresult`, `app.callServerTool()`) plus a FastMCP adoption-demand watchlist signal, and the 2026-09-19 re-pull added the protocol-site framing (**postMessage-only** wire dialect with `App` as an optional convenience wrapper) and the host-side **`@mcp-ui/client` + AppBridge** integration surface.
- **[OpenUI](/frameworks/openui.md)** — the declarative OpenUI Lang language + streaming runtime + Cloud backend.
- **[CopilotKit](/frameworks/copilotkit.md)** — the 1st-party AG-UI client that also renders A2UI and MCP Apps UIs; the 2026-09-19 re-pull archived `mcp-apps-demo` into the monorepo and confirmed the official docs statement that "messages, state updates, tool calls, and agent lifecycle events all flow through AG-UI".
- **[Mastra agentic-UI](/frameworks/mastra-agentic-ui.md)** — the agentic-UI layer (`@mastra/ai-sdk`) and UI dojo that drive multiple frontends; the 2026-09-19 re-pull finally resolved the **Mastra OpenUI integration page** (stream Mastra agent output into OpenUI through AG-UI).

The **2026-07-28 revision** removed the handshake/session (stateless core with optional `server/discover` RPC), added **Multi Round-Trip Requests (MRTR)** with `input_required`/`inputResponses`, header-based routing (`Mcp-Method`/`Mcp-Name`), cacheable list results (`ttlMs`/`cacheScope`), **full JSON Schema 2020-12 for tool schemas** (SEP-2106) and the `-32002`→`-32602` error-code change (SEP-2164), authorization hardening (RFC 9207 `iss` validation, issuer-bound credentials, **DCR formally deprecated in favor of CIMD**), **Tasks** as the `io.modelcontextprotocol/tasks` extension, a formal **extensions framework**, and a feature lifecycle policy with a 12-month deprecation window (Roots/Sampling/Logging + HTTP+SSE deprecated); Standards Track SEPs now need conformance-suite scenarios before Final (SEP-2484; SDK tier system PR 1777).
