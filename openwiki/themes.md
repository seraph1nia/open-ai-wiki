## Notes

- **mcp-core-standardization** — Introduced 2026-08-17 by the Agent integration protocols web-search run (3 queries over the MCP blog, spec releases, and ext-apps repo). Primary-source signals: the 2026-07-28 spec revision (stateless core; MRTR; header-based routing; cacheable list results; authorization hardening incl. RFC 9207 `iss` validation, issuer-bound credentials, and DCR deprecation for CIMD; Tasks moved to the `io.modelcontextprotocol/tasks` extension; extensions framework; deprecations), the release cadence 2025-03-26 → 2026-06-18 → 2025-11-25 → 2026-07-28, the 2026 roadmap (transport scalability, agent communication incl. Tasks lifecycle gaps, governance working groups, enterprise readiness), and the MCP Registry preview. The **2026-08-18 re-pull** added the full 2026-07-28 announcement SEP changelog (`server/discover` RPC, MRTR `input_required`/`inputResponses`, `Mcp-Method`/`Mcp-Name` headers, `ttlMs`/`cacheScope` caching), the 2025-11-25 anniversary release detail (Tasks states, CIMD SEP-991, extensions concept, enterprise-registry vision, Registry ~2,000 entries / 407% growth), the Tier 1 SDK GA posture (TS/Python/Go/C# speak the revision; Rust beta) with the TypeScript v2.0.0 monorepo split, and the `mcpb` packaging companion (manifest v0.4 UV runtime). See the [MCP page](/protocols/model-context-protocol.md), its [releases reference](/references/model-context-protocol-releases.md), and the [source page](/sources/web-search-agent-integration-protocols.md).
- **factory-toolchain** — Introduced 2026-08-16 by the Factory tools runs. The durable evidence so far is the AHP `mcp://` → MCP Apps link, the tool definitions (Pierre, t3code, OpenCode SDK, Pi SDK), and — after the second pull — Effect's durable-execution core (DurableQueue ported from v3, `@effect/workflow` in alpha). The **third pull** added ACP's Rust/schema artifact-versioning model and GitHub Copilot CLI as an official ACP server instance. The **2026-08-17 run** (17 queries, first blog-feed run) added the CI-native gh-aw layer (Markdown → Actions compilation, agent taxonomy, MCP gateway `gh-aw-mcpg` watchlist), Zed's DeltaDB human-agent shared-state design, Solo.io's gateway-side MCP progressive-disclosure/OBO themes, and Mastra 1.0/A2A/AI-Tracing runtime signals. The **2026-08-18 run** (17 queries, second blog/toolchain pull) deepened the gateway layer (Solo progressive disclosure quantified at up to 91% token savings; Solo Enterprise for agentgateway 2.2 hosted-MCP auth; kagent context-aware Kubernetes), added Mastra's agent-loop-orchestration-on-AI-SDK-v5 + nested-streaming capability, and captured t3code's nightly release stream. Mastra's UI-dojo post was **not re-adopted** (already synthesized from the generative-UI run; ledgered as `none` — see the [ledger](/sources/blog-post-ledger.md)). See the [hub notes](/concepts/factory-toolchain.md) and the [source page](/sources/web-search-factory-tools.md). Promote only as releases/relationships accumulate.
- **agent-maintained-knowledge-bases** — Introduced 2026-08-17 by the Agent wiki web-search run over the OKF spec and the OpenWiki repo. First-seen signal: knowledge corpora written and maintained *by agents*, with provenance/trust/lifecycle made first-class in frontmatter (OKF v0.2's `sources`, `generated`/`verified`, `status`/`stale_after`, `Attested Computation`) and tooling that operationalizes it end-to-end ([OpenWiki](/frameworks/openwiki.md): deterministic connectors, agent synthesis, visualizer, CI self-update). The 2026-08-18 re-pull surfaced three more independent producers (okc — schema-to-bundle, OKF v0.1; erd2okf — regeneration + drift CI check design; okf-gem — agent skill + CLI + `okf-mcp`, OKF v0.2), strengthening the theme from watchlist toward source-backed ecosystem; no formal implementations registry exists yet (AKB issue #86 asks upstream for one). Keep source-backed and revisit as releases/relationships accumulate.
