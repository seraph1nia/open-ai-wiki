## Durable facts adopted (condensed)

- The **2026-07-28 MCP specification** is the current revision: stateless core (no handshake/sessions; `initialize`/`initialized` and `Mcp-Session-Id` retired per SEP-2575/SEP-2567, optional `server/discover` RPC), MRTR (SEP-2322), header-based routing (SEP-2243), cacheable list results (SEP-2549), authorization hardening, formal extensions framework, Tasks as an extension (SEP-2663), deprecations, and a formal deprecation policy; RC was 2026-05-21.
- **MCP authorization** is OAuth 2.1-based; **CIMD (Client ID Metadata Documents — an HTTPS metadata URL used as the client ID) replaces DCR for new implementations**, with DCR now **formally deprecated** (kept for backward compatibility, removed in a future version); RFC 9207 `iss` validation is required of clients, `application_type` set during DCR, and client credentials are issuer-bound (SEP-2468/837/2352). Software statements are optional for `localhost`-impersonation trust, with SSRF protections for authorization servers making outbound requests.
- **2026-07-28 deprecations:** Roots, Sampling, and Logging (SEP-2577) plus the legacy HTTP+SSE transport — they keep working for at least **twelve months**; new implementations shouldn't adopt them.
- **MCP Registry** launched in preview (2025-09-08) as an open catalog/API for public MCP servers; by the 2025-11-25 anniversary it held ~2,000 entries (407% growth from September), and the 2025-11-25 release added an enterprise self-managed registry vision.
- **2026 roadmap**: releases → Working Groups; priority areas transport evolution/scalability, agent communication (Tasks lifecycle gaps), governance maturation (contributor ladder, delegation), enterprise readiness.
- **Tier 1 SDK posture:** TypeScript, Python, Go, and C# all speak 2026-07-28 on release day (migration notes included); Rust SDK in beta. The **TypeScript SDK shipped a v2.0.0 monorepo split** (core/client/server/node/hono/fastify/express/server-legacy/codemod at 2.0.0, following 1.30.0); Go `v1.7.0-pre.1` and C# `2.0.0-preview.1` were the observed beta packages; Swift through 0.12.1 with 0.11.0 covering 2025-11-25 conformance + SEP-973/1034/1036/1330 but not Tasks/sampling-with-tools/auth.
- **2025-11-25 revision (prior stable) detail added:** experimental core Tasks with states `working`/`input_required`/`completed`/`failed`/`cancelled`; CIMD URL-based client registration (SEP-991); the extensions concept (optional, additive, composable, independently versioned); security features (SEP-1024, SEP-835).
- **MCP Apps extension detail re-confirmed/extended:** 4-phase UI lifecycle (discovery, initialization, data delivery, interactive), `content` vs `structuredContent` separation, Python SDK (`mcp`) alongside TS (`@modelcontextprotocol/ext-apps`), Java SDK support **missing** as of v0.17.2 (issue #780); SEP-1865 (csharp-sdk #1431) frames it as the first official extension co-developed by Anthropic and OpenAI.
- **New companion repo surfaced:** `modelcontextprotocol/mcpb` releases (v2.1.2 latest observed; v2.1.0 adds experimental UV runtime support in manifest v0.4 and removes `_meta` from manifest v0.1) — a packaging/registry companion, tracked on the releases reference.
